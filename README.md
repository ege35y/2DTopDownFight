# 2D Top-Down Action Prototype

Unity 2D ile geliştirilmiş, akıcı dövüş mekanikleri ve kamera takibine odaklanan prototip.

### 🎮 [Oyunu itch.io Üzerinde Oyna](https://ege35y.itch.io/2d-top-down-fight)

[![Play on itch.io](https://ege35y.itch.io/2d-top-down-fight)

---

## 🕹️ Kontroller
* **WASD ** Hareket
* **Space ** Başlat / Saldırı
* **ESC ** Çıkış

## ⚙️ Teknik Özellikler
* **Motor & Platform:** Unity 2D (WebGL Build)
* **Girdi Sistemi:** Unity New Input System
* **Fizik:** Rigidbody2D tabanlı hareket ve çarpışma kontrolü
* **Kamera:** Yumuşak takip (Smooth follow) algoritması
* **Kodlama** Basit ve anlaşılabilir kod
